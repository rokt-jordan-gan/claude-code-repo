Rokt selectPlacements test page

Dummy confirmation page for firing a single Web SDK placement call.

Call configuration

Every field can be overridden by query string, e.g. ?email=someone@example.com&identifier=testsurvey.stg.rokt.conf&sandbox=1&autorun=1. sandbox: true points the SDK at apps-demo.rokt.com instead of production — leave it off unless Rokt told you to use the demo environment.

Embedded placement target

Overlay placements render over the page and ignore this container.
