Rokt SDK+ selectPlacements test page

Dummy confirmation page that initializes the Rokt Ecommerce Web SDK and fires one placement call.

Init & call configuration

The SDK initializes on the first run, using whatever is in the fields at that moment; the API key, domain, dev-mode and identity are then locked in — reload the page to change them. Everything is overridable by query string, e.g. ?email=someone@example.com&identifier=testsurvey.stg.rokt.conf&dev=0&autorun=1.

Embedded placement target

Overlay placements render over the page and ignore this container.
